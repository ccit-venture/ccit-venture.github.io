Tutorial pendamping [Sesi 5: Bikin Produk Mini Pertama Kamu](05-produk-mini-pertama). Baca dulu konsepnya di sesi itu, lalu ikuti langkah ini sampai produk kamu online.

## Langkah 1: Siapkan Folder Project

Buat folder baru bernama `produk-mini-ku` di laptop kamu. Di dalamnya buat tiga file: `index.html`, `style.css`, `script.js`.

## Langkah 2: Isi index.html

Salin kode index.html dari sesi 5 (bagian "Kenalan dengan Tiga File"). Ganti teks "Nama Kamu" dengan nama kamu, dan isi baris jurusan dengan jurusan kamu.

## Langkah 3: Isi style.css dan script.js

Salin kedua file dari sesi 5. Boleh diubah-ubah warnanya sesuai selera. Tapi ingat aturan sesi 2: kalau kamu mengubah kode, kamu harus paham apa yang kamu ubah.

## Langkah 4: Uji di Browser

Buka file `index.html` di browser (klik dua kali file-nya). Yang harus terjadi:

- Halaman tampil dengan kartu profil di tengah
- Saat tombol "Ganti Warna" diklik, warna latar kartu berganti

Kalau tidak berjalan, buka konsol browser (klik kanan → Inspect → Console). Error JavaScript muncul di sana. Salin pesan errornya, tanyakan ke AI, dan perbaiki.

## Langkah 5: Kalau Stuck, Pakai AI dengan Cara yang Benar

Jangan menyalin kode dari AI secara membabi buta. Gunakan alur dari sesi 2:

1. Jelaskan ke AI apa yang kamu buat dan apa yang tidak berjalan
2. Minta AI menjelaskan bagian yang kamu tidak paham
3. Minta AI menyarankan perbaikan, bukan langsung kasih jawaban utuh
4. Pastikan kamu bisa menjelaskan setiap baris yang masuk ke project kamu

Kalau kamu memakai AI agent (seperti freebuff) yang bisa mengerjakan langsung di project kamu, berlaku aturan yang sama, ditambah satu aturan tambahan: **minta agent menjelaskan setiap perubahan yang dia buat, dan kamu harus bisa menjelaskan ulang sebelum lanjut ke langkah berikutnya.**

Contoh prompt yang baik saat stuck:

> "Aku bikin halaman profil dengan tombol ganti warna. Tombolnya tidak bereaksi saat diklik. Ini kodeku: [tempel kode]. Jelaskan penyebabnya dan cara memperbaikinya, dalam bahasa Indonesia."

## Langkah 6: Deploy ke Vercel

Ulangi alur dari [Tutorial Deploy ke Vercel](tutorial-deploy-vercel):

1. Buat repository GitHub bernama `produk-mini-ku`
2. Upload tiga file (`index.html`, `style.css`, `script.js`) ke repository
3. Di Vercel, pilih "Add New Project", import repository itu, klik Deploy
4. Dapat URL live

## Langkah 7: Uji dari Perangkat Lain

Buka URL dari HP kamu. Coba klik tombolnya dari HP. Kalau berfungsi, produk kamu benar-benar berfungsi di internet, bukan cuma di laptop kamu.
